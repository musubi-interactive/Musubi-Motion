# Splat selection sets and scalar masks

Open `examples/splat-mask-regions.msb` for two independent instances of one original513-record source. The upper object has a Left originals quick-select set, binary/ramp masks and an empty Paint study; the lower instance has its own data. Regenerate it with `node scripts/create-splat-mask-example.mjs`. No external models or artwork are used.

Select a loaded splat object, then open **Select → Quick Select Sets / Paint Splat Masks**. **Choose components…** opens existing Splat Components: use box, lasso or Paint Selection, then return to the mask dock. **Create set from selection** saves original component IDs; **Select set members** recalls active, opaque originals. Replace/add/remove membership, rename or delete the set. Recall publishes hard membership (weight1); a saved set does not store a transient Soft Selection falloff.

**Create mask from selection** gives selected IDs value1 and all other originals0. **Create empty mask** starts at0. Choose a mask and **Start painting mask**. Replace blends toward Value; Add adds Value; Erase subtracts Value; Strength and Constant/Linear/Smooth falloff control influence. Coverage is the strongest continuous capsule coverage in a stroke, independent of pointer-event frequency. Smooth blends toward immutable eligible-center averages in neighboring3×3 screen cells of32pixels; Gaussian points have no mesh adjacency. It is a screen-space smoothing adaptation, not skin-weight normalization.

Paint uses the existing posed original-center eligibility: hidden/deleted, clipped, transparent and generated elastic-fill IDs are excluded. Painting is through surfaces; it does not test Gaussian depth or occlusion by another object. **Paint selected components only** additionally restricts the brush. Drag to preview; release authors one undoable stroke. Escape, pointer cancel, camera/scene/selection change or lost window focus discards it exactly. Hold **B + left-drag** to resize the brush without authoring mask data. Brush fields use right-aligned values, middle scrubbing and right-click session Lock/Unlock. Native text focus is preserved.

**Show mask overlay** shows dark0 to white1 at posed original centers while this dock is visible. Up to20,000 markers are sampled for display, independently of authored data or membership. Sparse changes are prioritized; status gives the full count. Original colors, Gaussian coefficients, SH, source bytes and skin weights remain unchanged.

**Lock mask layer** prevents mask edits. **Lock selected mask components** protects those original IDs from brush, flood, invert and combine; **Unlock all mask components** clears the component locks. Locks are saved. Flood sets all original values to Value (Erase uses0), Invert computes1−value, and Combine supports Add/Subtract with0–1clamping, Multiply, Minimum or Maximum into the current mask. These whole-mask operations include hidden/deleted originals and preserve component locks. Hide/delete alone never changes stored masks/sets; show/restore reactivates the same original correspondence. Select mask region recalls values at or above the threshold, filtered by current eligibility.

Masks are local deterministic0–1 scalars, read by `maskValue(mask, originalIndex)`. Each shape owns its collections even when multiple shapes share one asset. Storage switches between canonical sparse defaults/exceptions and dense values; arrays store original indices, never renderer ordering, LoD records or generated fill. The current Scenev2/MSBv1 representation adds optional `selectionSets`/`scalarMasks` to splat shapes. Every collection records version1, original asset ID/count and stable ID/name. Unsupported versions, malformed values/ranges, source mismatch and oversized archives reject atomically. Actual decoded count is checked before replacing a loaded scene.

Limits:32sets and16masks per shape,256collections per scene;1,000,000 members per set or component-lock set;1,000,000stored values per mask;4,000,000stored numeric values/indices/range endpoints per scene (32MB numeric payload). A paint index supports1,000,000eligible projected centers and one stroke at most100,000edited IDs; excess rejects the complete stroke without truncation. Use smaller strokes or selected-only painting. Multiple strokes can build larger masks. Masks on sources up to134,217,728originals can use sparse storage. At most128MiB of structurally shared numeric mask/set history is retained: current+immediate-undo are checked before authoring, then only older history is trimmed. These bounds do not cap source-file or GPU memory; existing editor limits still apply.

Musubi maps quick-select commands to its existing Select menu and a dedicated dock, rather than adding a whole Create/Sets hierarchy. Existing F8 component mode and explicit brush controls retain browser focus conventions. Text labels communicate each operation; no Autodesk artwork/code is copied.

Implementation: original mask/set data, scalar stroke evaluation, preview/UI and fixture; reuse of the editor's generic clipped projection index, existing Three.js0.180.0 (MIT) Points/line/geometry and Spark2.4.0 (MIT) evaluated original centers. No added/upgraded dependency, service, model or source data obligation.
