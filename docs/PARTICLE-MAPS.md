# Texture emission maps

Open `examples/particle-map-study.msb` for the original M logo and animated noise × gradient examples. Scrub the timeline forward and backward; reopening repeats the same particle counts and positions for the same seed and authored scene. Rebuild the example with `node scripts/create-particle-map-example.mjs`.

1. Select a polygon mesh in the Outliner. Open **FX → Particle Emitters**, choose **Mesh surface**, then **Create particle emitter**.
2. Import a still PNG, JPEG, or WebP in **View → Texture Assets**, or author the scene graph in **View → Texture Graph**. The graph's Output is the emission source; no material assignment is needed.
3. Select the emitter. In **Emission → Texture Emission Attributes**, choose the source, image if applicable, projection and channel, then turn on **Enable Texture Rate**.
4. Use **Surface UV (UV0)** for the mesh's authored UV coordinates. A mesh without UVs is rejected visibly. Alternatively choose **Local XY/XZ/YZ** and set positive projection bounds in mesh rest coordinates. UV origin is lower left; samples outside 0–1 clamp to the image edge. Image sampling is nearest pixel. The example planes use Local XZ with bounds −1.5 to 1.5 on both axes.
5. Adjust **Density strength** from 0 to 1. The base rate schedules candidates; the sampled map is their probability of emission, multiplied by strength. Zero emits no particles. Values outside 0–1 clamp when sampled; authored strength outside 0–1, negative/nonfinite rates and invalid bounds are rejected atomically. **Emit From Dark** inverts density before strength. The existing per-emitter/scene capacity limits still apply to the base rate and lifetime.

Luminance is mean linear RGB, following Maya's equal-channel interpretation after the asset's Color (sRGB) or Data (Raw) role is applied. Alpha is always linear. Procedural Position receives the sampled mesh-local rest position; UV receives the selected projection. Graph Time receives **absolute historical birth frame ÷ scene FPS**. A fixed 120 Hz birth group uses its beginning frame, matching the existing particle transform sampling. This is independent of viewport rendering frequency and scrub direction. Changing scene FPS without rescaling authored frame ranges changes their duration, as with the rest of the timeline.

Numeric typing and middle-drag preview immediately in the viewport. Enter/blur or releasing a scrub commits one undoable edit. Escape or pointer cancel restores the original authored value and replay. Right-click a numeric field to Lock/Unlock for this session. Selection, locks, draft values, decoded pixels and GPU resources are not archived. Enabling/disabling and choosing sources commit single undoable commands. A referenced image, even on a disabled image map, must be relinked before deletion; Texture Assets lists particle references and relinks them together with materials/graph references.

Maps only affect mesh surface emitters. Untextured emitters retain their existing simulation. Surface particles use rest mesh geometry with historical object transforms, matching the current particle system; deforming/skinned surface emission is outside this slice. Emission does not paint vertex colors or change original texture files. No external service, model or additional dependency is used.

Bounds: 32 emitters, 20,000 potential live particles per emitter and 100,000 across the scene; 300 seconds emission; 120 simulation steps/second. A map uses at most four graph images. The scene permits 8,388,608 decoded pixels (32 MiB RGBA) across active emitter instances; an image used by two emitters counts twice because each replay owns its pixels. Disabling a texture map releases its decode budget. Replay yields to keep the editor responsive and superseded requests cannot publish stale output. Complex scenes and long seeks can still require noticeable replay time; runtime status reports replay/errors.

Functional reference: Autodesk Maya 2026, [Scale nParticle emission rate using a texture](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-SimulationEffects/files/GUID-A01C6D87-1EC1-49CE-A270-B0D76647D6CC.htm). Musubi keeps the surface-parented Outliner emitter and Texture Emission Attributes / Enable Texture Rate / Emit From Dark terminology. Existing asset/graph selectors replace Hypershade middle-drag assignment; numeric middle-drag retains Musubi's established scrub/undo conventions. No Maya artwork or code was copied.
