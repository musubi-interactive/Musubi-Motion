# Paint Splat Attributes

Open **Select → Paint Splat Attributes** with one splat object selected. Choose Color (RGB), Opacity (Alpha), or both. Set the brush radius in viewport CSS pixels, strength, and falloff, then click **Start Painting**. Drag with the primary pointer. The viewport previews the actual edited splats. Release commits one undo step. Escape, lost capture, a changed scene or selection, and camera motion restore the prior layer. Hold B and drag to resize the brush. Numeric fields support middle-drag and the field's Lock/Unlock menu.

- **Front Centers** uses the nearest opacity-eligible posed center per 4 × 4 CSS pixel cell on the selected object. This estimates overlap between its splats using center depth. **Through** reaches both depths and splats hidden by low opacity. Hidden and deleted originals are excluded in either mode.
- **Scalar Mask** scales stroke coverage by an existing per-splat mask. **Selected Splats Only** limits coverage further to the active component selection. Depth is resolved before either restriction, so an excluded foreground center does not expose a rear center in Front Centers mode.
- **Replace** paints the selected channels toward the brush target. **Erase** reduces their paint coverage to reveal the underlying attributes. **Clear Paint Layer** removes the shape's full paint layer in one undoable edit.

A shape has one sparse paint layer keyed by original splat ID. Color targets entered in the RGB picker are decoded from sRGB and blended in linear light with the shaded source, including its spherical harmonics and any texture graph appearance. Coverage at one fully replaces the shaded color. Erasing reveals it again. Opacity is an absolute target from zero to one, blended after texture appearance. CPU selection uses the same composed opacity with Spark's existing pick threshold. The covariance modifier preserves skinning and original Gaussian geometry. The layer disables LoD on the affected object to preserve original indexing. Generated elastic fill keeps its existing appearance.

MSB archives store the version, original source count and sorted paint records. Geometry and image bytes stay immutable. Brush settings, active strokes and GPU resources stay in the editor session. The current limits are 1,000,000 originals per brush source, 100,000 edited originals per stroke or shape, 250,000 paint records per scene, and an estimated 64 MiB paint history budget. Each GPU record occupies 32 bytes plus texture row padding. Brush latency depends on the number of projected centers, pose, and affected records.

The dock follows Maya's Paint Vertex Color Tool workflow for RGB/Alpha/RGBA, Replace and Remove, and Artisan brush controls. Musubi's Select menu groups the tool with its existing splat component and mask workflows. Existing scene focus and gizmos resume when painting stops. Text labels identify brush actions.
