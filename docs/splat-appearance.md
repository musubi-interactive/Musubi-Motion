# Splat appearance

Open `examples/textures/splat-appearance.msb`, select **Planar Appearance** in the Outliner and open **View → Splat Appearance**. Frame 0 shows a warm, enlarged left region and a source-colored right region. At frame 48 the moving left region passes under a transparent stripe in world space. Seek backward to restore the earlier view. The embedded graph uses a gradient and Noise driven by Time × Multiplier for RGB, and an embedded image for Alpha.

The dock applies the scene Texture Graph Output to one splat shape. Add up to four layers and move them earlier or later. Each layer has a scalar mask, blend amount, independent Color, Opacity and Scale switches, and planar projection. Use **Select → Quick Select Sets / Paint Splat Masks** to paint the mask. A mask can drive multiple layers. Reassign layers before deleting a referenced mask.

- **Object** projects from edited rest centers. Skinning carries the result with the splat. **World** projects from the current component-edited, skinned world centers, including transform animation. XY, XZ and YZ specify U, V and the remaining depth coordinate in that order. For each projected axis, the graph receives `axis × scale + offset`. Texture Sample clamps to image edges, while procedural Position receives the projected depth as its third component.
- Earlier layers evaluate first. Each layer interpolates enabled channels toward its graph output by `mask × blend`. Color blends the graph's linear RGB with the shaded source color, including its spherical harmonics contribution. Opacity interpolates the current source-opacity multiplier toward graph Alpha. Scale interpolates an isotropic multiplier toward the range between **Scale at Alpha 0** and **Scale at Alpha 1**. Deleted and hidden original IDs stay inactive. Generated elastic fill keeps its existing appearance.
- Type a value or middle-drag a numeric field for live preview. Release to commit one undo step. Escape restores the prior value. Use the field's right-click menu for Lock/Unlock.
- The MSB stores layer settings, mask IDs and the source count alongside the existing graph and embedded texture. Runtime coefficients, GPU textures, pointer drafts and selection stay in the editor session.

Spark 2.4 applies the coefficient texture after source SH sampling. The render path and CPU selection share published opacity and scale. The picker uses Spark's existing opacity threshold of 0.2, so a faint Gaussian can contribute to the image while being below the selection threshold. Object ray picking tests the scaled ellipsoid. Component picking still uses projected centers. Appearance disables LoD on affected objects so masks and coefficients address original splat IDs. Scene framing uses expanded local bounds and the current posed ellipsoid bounds for bound shapes.

The runtime supports 250,000 originals per affected object and 500,000 across the scene. Two reusable RGBA32F buffers use approximately 32 MiB CPU at the scene limit, with 16 MiB uploaded. Partial 1024-texel rows add less than 32 KiB of CPU and 16 KiB of GPU padding per affected object. The graph's existing 8,388,608 image-pixel limit bounds the decoded cache at 32 MiB. A replacement image set is staged before publication. If a projection produces a nonfinite graph sample, the viewport and picker retain the last valid coefficients and the dock reports the error. Static appearance reuses coefficients while the input graph, stack, masks and projected coordinates are unchanged. Animated, deformed-world and active gesture changes can resample the original IDs, so maximum-size complex graphs can take longer than a display frame.

The contextual dock follows the Maya Projection and Layered Texture workflows. Numeric placement controls cover the supported planes and preserve the current object selection, gizmo and keyboard conventions. Layer action buttons use explicit text labels. [Maya 2026 Projection](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-Tech-Docs/Nodes/projection.html), [Maya 2026 Layered Texture](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-Tech-Docs/Nodes/layeredTexture.html), [Maya Projection utility workflow](https://help.autodesk.com/cloudhelp/2022/ENU/Maya-LightingShading/files/GUID-389BBAD7-9E18-4677-9F20-1AFB8C080942.htm).
